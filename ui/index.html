    How To Use ripper
    part of O'Tool

    1. Get an image

    Start ripper from ShareX, press PASTE (Ctrl+V), drop a file on the window or press OPEN. A new image clears the current quads.

    2. Mark quads

    Click the four corners of a flat surface: top-left first, then around it. Drag any corner to adjust. Click a quad or its row to make it active. A red quad crosses itself or is too thin and will not export.

    3. Size

    EDGES sizes the texture from the quad's edges. A locked ratio keeps that width and sets the height. Power of two snaps both sides to 256, 512, 1024 and so on.

    4. Output

    SEND ACTIVE puts the active quad on the clipboard, into the enabled folders and, from ShareX, back into ShareX, then closes. SAVE ALL writes every quad to the folders. Existing files are never overwritten.

    5. ShareX setup

    Task settings, Actions, Add: point to ripper.exe, arguments "$input" "$output", output extension tex.png (a plain png would overwrite the original capture). In After capture tasks enable Save image to file and Perform actions. ShareX waits while ripper is open, so finish or press Esc before the next capture.

    6. Atlas

    Tick Atlas in Output and every SEND or SAVE ALL also lands as a tile in the current workspace, ShareX captures included. Switch to ATLAS to arrange them: the canvas holds square sectors of one size; select a sector and use its + buttons to add neighbours. New tiles fill the free space of the last selected sector; what does not fit waits beside the grid and is not exported. Drag tiles, scale them by a corner, rotate with R. EXPORT writes one sector, the selected sectors as one sheet, or a numbered set (name.1001.png...). SAVE keeps everything in a .ripper file.
